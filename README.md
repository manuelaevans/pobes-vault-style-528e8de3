# Pobe's Vault Revamp

POBE’S VAULT — COMPLETE WEBSITE FIX & DEVELOPMENT BRIEF

1. PROJECT OVERVIEW



I want to improve and expand the existing Pobe’s Vault website, rather than completely redesigning it.



Pobe’s Vault is a fashion retail business. We source and resell carefully selected clothing, footwear and accessories from different brands and suppliers.



The website should therefore function as a complete online retail store, not simply a page displaying products.



The main purpose of the website is to help customers:



Discover products → Search → Browse → View product details → Select options → Add to cart or order via WhatsApp → Complete their order



The existing Pobe’s Vault identity and dark aesthetic should be maintained, but the website should feel more polished, modern, professional and easier to use.

3. SEARCH BAR



A prominent search bar should be included as part of the main shopping experience.



It should not be hidden only behind a small search icon.

Place the search bar clearly within or immediately below the main navigation/header.



Example:

Mobile



Place the search bar directly below the main header/navigation so customers can see it immediately.



Example:



POBE’S VAULT



[ 🔍 Search products, brands or categories… ]



The search bar should be wide, easy to tap and clearly visible.



Search should work with:

Search results should display matching products using the normal product-card layout.



If possible, include search suggestions/autocomplete while the customer types.



Search should also work together with product filters.
